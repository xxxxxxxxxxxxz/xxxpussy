# XXXPUSSY

Project files:
- index.html: public gallery
- admin.html: administrator login and upload page
- css/style.css: website design
- js/config.js: backend URL and publishable key
- js/gallery.js: gallery and search
- js/admin.js: admin login and picture management
- supabase/setup.sql: database and storage policies

The ad areas are placeholders. They do not generate income until an ad network approves the website and you install its official ad code.

Before publishing:
1. Confirm the hosting and backend provider explicitly allow your intended content.
2. Create an administrator account and disable public account registration.
3. Create a public storage bucket named gallery-images.
4. Run supabase/setup.sql in your backend SQL editor.
5. Add your project URL and publishable/anon key in js/config.js.
6. Never put a password or service-role/secret key into public JavaScript.
7. Only publish content you have permission to distribute and that depicts consenting adults.
